# Alto Zañartu — Landing Page

Landing page inmobiliaria para el proyecto **Alto Zañartu** (Corregidor Zañartu 11544, La Florida), desarrollado por **Constructora Vector** y comercializado por **OneKey**.

## 🌐 Sitio Web en Vivo (GitHub Pages)
👉 **[https://lupdesign.github.io/landing-alto-zanartu/](https://lupdesign.github.io/landing-alto-zanartu/)**

---

## 📁 Estructura del Proyecto
- `index.html`: Maquetación completa de la landing page (HTML5, CSS3 y JS vanilla).
- `AGENTS.md`: Reglas de diseño, paleta de colores, tipografía y lineamientos de marca.
- `assets/logos/`: Logotipos e isotipos oficiales en formato SVG.
- `fuentes/`: Tipografías locales de marca (`Roboto Condensed` y `Work Sans`).
- `media/`: Video hero, plantas isométricas (`D1` a `D4`), mapa de ubicación y renders del carrusel.
- `Brochure.pdf`: Brochure descargable del proyecto.

## 💻 Flujo de Trabajo (Oficina ⇄ Casa)
1. **Primera vez en otra laptop (clonar repositorio):**
   ```bash
   git clone https://github.com/lupdesign/landing-alto-zanartu.git
   ```
2. **Al empezar a trabajar (descargar últimos cambios):**
   ```bash
   git pull
   ```
3. **Al terminar cambios (guardar y publicar en la web):**
   ```bash
   git add .
   git commit -m "Actualización landing"
   git push
   ```
